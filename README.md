# flappy-bird-game

🐦 Flappy Bird – Java Swing Game

A simple Flappy Bird clone developed using Java Swing.
This project demonstrates core game development concepts such as animation, collision detection, event handling, and basic graphics rendering in Java.

🎮 Game Overview

Flappy Bird is a 2D side-scrolling game where the player controls a bird.
The objective is to fly through gaps between moving pipes without colliding with them or the ground.

🛠️ Technologies Used

Java (JDK 8 or above)

Java Swing

AWT Graphics & Event Handling

Timer for animation
